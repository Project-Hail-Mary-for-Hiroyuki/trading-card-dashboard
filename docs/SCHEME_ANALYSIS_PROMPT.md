# 構造化プロンプト: 利益スキーム分析と国内売却スキームへの転換設計

## 1. 役割定義
> あなたはTCGリセール市場に精通したデータアナリスト兼ビジネスアーキテクトです。trading-card-dashboard の現行スキーム（国内仕入れ→海外売却のクロスボーダーフリップ）を多角的に評価し、その上で「売却先を日本国内マーケットプレイスに変更し、日本語カードを出品するスキーム」への転換を設計せよ。結論は実データ（手数料・為替・物流コスト）に基づき、図表を用いて分かりやすく報告すること。

## 2. タスクA: 現行スキーム（国内仕入れ→海外売却）の評価

### A-1. 分析対象の現行フロー
```
仕入れ: メルカリ / Amazon / 駿河屋 (JPY)
  ↓ 為替 USD/JPY, EUR/JPY (fx_markup 3%)
売却:   TCGPlayer (手数料~10%) / eBay (~13.25%) / Cardmarket (~5%)
判定:   net = 売価×(1-手数料) - 送料500円 - 仕入値×(1+fx_markup)
        利益率 ≥20% 有望 / ≥50% 注目
```

### A-2. 評価観点（長所・短所をそれぞれ列挙）
1. **価格スプレッドの構造** — 日本語版と英語版カードの市場性の違い、日本限定レアリティの海外人気
2. **コスト構造** — プラットフォーム手数料、為替スプレッド・送金手数料(PayPal/Wise)、国際送料・追跡番号、関税・消費税の帰属
3. **流動性・回転率** — 海外マーケットの買い手数、売れるまでの期間、在庫リスク
4. **運用リスク** — 規約違反・アカウント停止、詐欺・チャージバック、国際返品、為替変動
5. **法的・税務** — 消費税の納税義務（輸出免税の要件）、所得税・雑所得申告、古物商許可の要否

## 3. タスクB: 国内売却スキームへの転換設計

### B-1. 要件
- 売却先を日本国内のマーケットプレイスに変更し、**日本語カードをそのまま出品**できるようにする
- 候補: メルカリ、ラクマ、Yahoo!かんたん決済を含むヤフオク!、駿河屋（委託販売）、トレコロ/ハリーズ等のTCG専業、リアル店舗買取
- システム側の変更点を具体的に列挙:
  - `price_sources.sell` の設定例（url_template / link_template を実URLで）
  - `FeeConfig.fee_for()` の手数料テーブル拡張
  - `analysis.compute_spreads()` の通貨換算簡素化（全てJPY化）
  - スプレッド計算式の再定義（国内送料・梱包材・振込手数料）

### B-2. 比較分析の枠組み
各売却候補について以下を表形式で比較せよ:
| 項目 | 内容 |
|---|---|
| 販売手数料率 | 公式の最新値 |
| 出品・振込関連コスト | 振込手数料、かんたん決済手数料等 |
| 流動性 | TCGカテゴリの取引量感 |
| 价格統制 | 買い切り/オークション、価格競争の激しさ |
| 入金までの期間 | 即時〜N日 |
| リスク | 返品・キャンセル規約、悪質購入者対策 |

### B-3. シミュレーション要件
同一カード（仕入1,000円）を(a)現行海外売却と(b)国内売却の両スキームで販売した場合の損益を、
手数料・送料・為替コスト込みで数値シミュレーションし、損益分岐の売価を求める。
